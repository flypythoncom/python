# Lesson 4: Verify like an engineer, review like a skeptic

## Objective

Complete the evidence loop — both verification directions, all three skins, a scope-creep diff review, and a written record of what is not proven.

## The lesson

Run `python verify.py starter` (9/9 after your change) and `python verify.py solution` (9/9 reference). Then run each skin end to end like a user, hand-check one group total, and review the diff: every change must be forced by a test. Write the three-line record: verified / not verified / known limits.

## Exercise

- Compare your record with REVIEW.md at the course root
- Try an empty data file — what happens?

## Checkpoint

The lesson's commands run, and you can explain — in your own words — what failed and why.

## Expected evidence

The command transcript and your answers. Lesson 4 asks for them again.
