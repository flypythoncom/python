# Lesson 3: Drive a bounded change, test by test

## Objective

Supervise Codex through seven small diffs — smallest change, no new dependencies, one failing test group at a time.

## The lesson

Tell Codex: "Work through TASK.md against starter/report_tool.py, one failing test group at a time; after each group run the suite and show me the diff before continuing." Expect the failing count to fall 7 → 5 → 4 → 3 → 2 → 0. If Codex edits `tests/`, `solution/`, or `scenario/` — stop and ask why. If it wants to change a test, the answer is no.

## Exercise

- Run PYTHONPATH=starter python -m unittest discover -s tests -v after each group
- Write the last group yourself when only end-to-end tests remain

## Checkpoint

The lesson's commands run, and you can explain — in your own words — what failed and why.

## Expected evidence

The command transcript and your answers. Lesson 4 asks for them again.
