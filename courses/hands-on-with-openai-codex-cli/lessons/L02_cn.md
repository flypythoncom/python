# 第 2 课：动手之前先写任务契约

## 目标

把“优化一下”变成有边界、可测试的陈述——驱动 Codex 杠杆最大的一项技能。

## 课程内容

打开 `TASK.md`。每一行都描述可观察的行为而非实现。把四条陈述对应到测试，然后为你自己的脚本写一条契约。边界条款（只改 `starter/report_tool.py`、只用标准库、不改测试）正是防止 Agent 出于好意的重写吞掉你项目的东西。

## 练习

- 让 Codex 参照 TASK.md 点评你的契约——它应该找歧义，而不是加功能
- 问它：“这几条里哪条你能靠作弊满足？”修掉任何没通过这一关的行

## 检查点

本课的命令运行通过，并且你能用自己的话说清什么失败了、为什么。

## 预期证据

命令输出记录与你的回答。第 4 课会再次用到。
