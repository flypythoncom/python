# Lesson 1: Reproduce the failure with Codex in the loop

## Objective

Run the verifier both ways, map each failing test to a real-world failure class, and learn how to hand the folder to Codex.

## The lesson

Run `codex` in the course folder and say "start lesson 1". Codex reads COURSE.md first — the teaching contract governs what it may touch. Then run the objective verification yourself:

## Exercise

- `test_load_json_records_returns_list_of_dicts` — only CSV works; the API skin crashes
- `test_invalid_records_are_isolated_with_reasons` — one empty cell aborts the whole run
- `test_group_totals_are_rounded_to_two_decimals` — `0.1 + 0.2` prints `0.30000000000000004`
- `test_write_report_creates_missing_parent_directories` — fresh output directories fail

## Checkpoint

`python verify.py starter --expect-failure` reproduces the listed failures and `python verify.py solution` passes — and you can name the four missing behaviors without looking.

## Expected evidence

The command transcript and your answers. Lesson 4 asks for them again.
