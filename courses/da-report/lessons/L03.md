# Challenge 03: Build and render the report

**Gate:** objective — starter suite · **Points:** 10

Implement the contract in `starter/report.py`. Watch for:

- Recomputing metrics instead of carrying inputs through — the suite
  compares numbers exactly.
- Headings drifting from the spec — `## Data quality`, `## Findings`,
  `## Appendix`, in that order.
- Number formatting: `33347.89` must appear with two decimals.

**Checkpoint:** `python verify.py starter` exits 0. Claim code via
`python verify.py`.
