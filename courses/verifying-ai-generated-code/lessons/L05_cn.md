# 给你的下一次发布装上门禁

## 目标

把 ship check 带到你自己的项目，让记录成为交付的一部分。

## 课程内容

为你的一个项目加上 ship.json（命令 + 未验证清单），放入 ship_check.py 并运行。把退出码接进你已有的任何门禁——CI、发布脚本或人工清单。从现在起，“已交付”意味着记录存在、且你读过它的未验证清单。

## 练习

- 在干净检出上运行检查；记录必须可复现

## 检查点

本课的命令运行通过，并且你能用自己的话说清什么失败了、为什么。

## 预期证据

命令输出记录与你的回答。
