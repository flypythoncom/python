# Gate your next release

## Objective

Take the ship check to a project you own and make the record part of shipping.

## The lesson

Add ship.json to one of your projects (command + unverified list), drop in ship_check.py, and run it. Wire the exit code into whatever gate you already have — CI, a release script, or a human checklist. From now on, "shipped" means a record exists and you have read its unverified list.

## Exercise

- Run the check from a clean checkout; the record must reproduce

## Checkpoint

The lesson's commands run, and you can explain — in your own words — what failed and why.

## Expected evidence

The command transcript and your answers.
