# Validation and error isolation

## Objective

Arguments are untrusted input: validate before execution, and never let a handler crash the transport.

## The lesson

Two boundaries make a tool server safe: validate required arguments against the declared input schema (missing arguments become structured results, not exceptions), and wrap every handler so its failures return isError instead of breaking the connection. 03-missing-argument.json shows the first boundary on the wire.
