# 给你的 Agent 暴露一个真实工具

## 目标

把你真正拥有的一个函数包进刚建好的“校验 + 隔离”边界。

## 课程内容

从你自己的项目里挑一个只读函数——查询、摘要、计算。用显式 schema 把它注册为工具，复用校验与隔离模式，并在接线任何客户端之前先写失败测试。2026-07-28 迁移指南覆盖既有服务的迁移；这一课是你第一个做对的工具。

## 练习

- 从失败测试开始；schema 就是契约
- 记录哪些没验证（客户端合规性、传输行为）

## 检查点

本课的命令运行通过，并且你能用自己的话说清什么失败了、为什么。

## 预期证据

命令输出记录与你的回答。
