# Expose one real tool to your agent

## Objective

Wrap one function you actually own behind the validated, isolated boundary you just built.

## The lesson

Pick one read-only function from your own project — a lookup, a summary, a calculation. Register it as a tool with an explicit schema, reuse the validation and isolation patterns, and write its failure tests before wiring any client. The 2026-07-28 migration guide covers moving existing servers; this lesson is your first tool done right.

## Exercise

- Start with the failure tests; the schema is the contract
- Record what you did not verify (client compliance, transport behavior)

## Checkpoint

The lesson's commands run, and you can explain — in your own words — what failed and why.

## Expected evidence

The command transcript and your answers.
