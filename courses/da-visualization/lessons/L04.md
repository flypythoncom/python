# Challenge 04: Numbers match the charts

**Gate:** objective — both suites · **Points:** 10

The suite verifies `summary.json` against the dataset's ground truth
(East 12334.94, North 14294.7, South 11200.48, grand total 37830.12,
45 days). A chart that shows different numbers than the JSON is a failed
chart — the JSON is the auditable layer.

`python verify.py starter --expect-failure` must now exit nonzero;
`python verify.py solution` must be green.

**Checkpoint:** both gates pass. Objective claim code via
