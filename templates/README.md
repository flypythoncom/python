# Reusable templates

- [Task contract](TASK_CONTRACT.md): outcome, boundaries, acceptance, authority.
- [Implementation plan](IMPLEMENTATION_PLAN.md): findings, steps, risks, rollback.
- [Code review](CODE_REVIEW.md): correctness, security, maintainability, evidence.
- [Verification record](VERIFICATION.md): exact commands and observed results.
- [Agent repository instructions](AGENTS.example.md): a starting policy for a
  Python repository using coding agents.
- [`pyproject.toml` example](pyproject.example.toml): a minimal quality baseline
  using a `src/` layout, pytest, Ruff, and mypy.

Chinese task and verification templates are provided alongside the English
versions.
